# 01a-swdev-frontend

A simple frontend app for the Unit Logbook assignment. It shows a list of log entries and allows users to add new ones.

- Displays existing entries from the sample data
- Lets users add a new entry with a title, message, and optional location
- Shows entries in reverse chronological order
